# China (People's Republic of China) — legislation as Markdown

Part of [LawCodex](https://github.com/LawCodex): the legislation of every country as plain Markdown in git.

This repository holds the **Constitution of the PRC (中华人民共和国宪法)**, the **national laws in force (法律)**,
the **administrative regulations in force (行政法规)** and a set of **judicial interpretations (司法解释)**,
in Simplified Chinese.

*Work in progress — counts and coverage are filled in when the import completes.*
